# WenKing 多页面应用框架实现方案

## Context

当前项目是一个 PHP 游戏模组网站（WenKing），已有首页（index.php）和关于页面（about.php），使用 Tailwind CSS CDN + Three.js GridScan 3D 背景动画。用户需要新增一个包含**仪表盘、设置、下载**三个页面的应用框架，采用 PHP 多页面 + AJAX 实现无刷新切换，侧边栏导航，与首页视觉风格统一。

## 实现步骤

### 第一步：创建应用入口 `app.php`

- 引入 config.php
- 通过 `$_GET['page']` 实现 PHP 端 SSR 路由（避免首屏闪烁）
- 引入 app-header.php、app-sidebar.php
- 创建 GridScan 背景容器 + 主内容区域 `#app-content`
- 引入 app-footer.php（GridScan 初始化 + app.js）

### 第二步：创建 `includes/app/app-header.php`

- 复用 header.php 的全部逻辑（Tailwind CDN、Three.js CDN、Google Fonts、颜色配置）
- 额外引入 `assets/css/app.css`
- body class 增加 `app-layout` 标识

### 第三步：创建 `includes/app/app-sidebar.php`

响应式侧边栏导航组件：

- **桌面端 (>= 1024px)**：固定左侧，宽度 260px，始终展开
- **移动端 (< 1024px)**：抽屉式，汉堡按钮触发，遮罩层关闭
- 导航项：仪表盘、下载、设置 + 返回首页
- 激活状态：紫色左边框 + 紫色背景高亮
- 使用 `data-page` 属性标记当前页面

### 第四步：创建 `includes/app/app-footer.php`

- GridScan 背景容器创建
- grid-scan.js 引入和初始化（复用 footer.php 中的逻辑）
- app.js 引入
- 不包含传统 footer（应用页面不需要页脚链接）

### 第五步：创建 `assets/css/app.css`

包含以下样式模块：

1. **侧边栏样式**：固定定位、宽度、过渡动画、激活状态
2. **布局样式**：主内容区域左边距（桌面端 260px）、内容容器
3. **表单元素样式**：输入框、下拉框、开关、表单组
4. **页面切换动画**：淡入淡出 + 位移效果
5. **响应式断点**：>= 1024px 展开 / < 1024px 隐藏 + 汉堡菜单

### 第六步：创建 `assets/js/app.js`

核心 JavaScript 模块：

1. **AppState 类** - 发布-订阅模式状态管理（currentPage, isLoading, sidebarOpen）
2. **Router 类** - Hash 路由（`#/dashboard`, `#/settings`, `#/downloads`）
3. **PageLoader 类** - AJAX 加载页面内容到 `#app-content`，含淡入淡出动画
4. **SidebarController 类** - 侧边栏展开/收起、激活状态更新
5. **App 主类** - 初始化协调，监听 hashchange 事件

### 第七步：创建 `api/router.php`

- 接收 `?page=xxx` 参数
- 白名单验证（仅允许 dashboard, settings, downloads）
- 引入对应 section 文件返回 HTML 片段
- 安全处理：防止目录遍历

### 第八步：创建页面内容

**`includes/app/sections/dashboard.php`**：
- 页面标题（渐变文字）
- 统计卡片网格（订阅状态、到期日期、下载次数、在线状态）
- 最近活动区域
- 快速操作按钮

**`includes/app/sections/settings.php`**：
- 页面标题
- 设置表单（账户信息、偏好设置、安全设置）
- 表单元素使用统一的 glass-card 风格
- 保存按钮

**`includes/app/sections/downloads.php`**：
- 页面标题
- 产品下载列表（卡片式，含状态标签）
- 下载历史区域

## 关键技术决策

| 决策 | 方案 | 原因 |
|------|------|------|
| 路由方式 | Hash 路由 (`#/dashboard`) | 无需服务器 URL 重写，兼容性好 |
| 首屏渲染 | PHP SSR 默认渲染 dashboard | 避免首屏白屏/闪烁 |
| 页面切换 | AJAX + 淡入淡出动画 | 无刷新体验，视觉流畅 |
| 状态管理 | 发布-订阅模式（原生 JS） | 无需引入外部库，轻量 |
| 3D 背景 | 复用 GridScan（固定定位） | 与首页视觉统一，不受 AJAX 影响 |
| 响应式 | Tailwind 断点 + CSS 媒体查询 | 与现有项目一致 |

## 验证方式

1. 访问 `app.php` 确认默认显示仪表盘页面
2. 点击侧边栏各链接确认 AJAX 无刷新切换
3. 缩小浏览器窗口确认移动端侧边栏抽屉效果
4. 确认 GridScan 3D 背景在所有页面正常显示
5. 确认浏览器前进/后退按钮正常工作
6. 确认页面切换动画流畅
